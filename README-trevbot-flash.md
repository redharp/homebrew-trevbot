# trev.bot flash

Install on Apple Silicon or Intel Macs with macOS 12 or newer:

```sh
brew install --cask redharp/trevbot/trevbot-flash
```

Open **trev.bot flash** from Applications. The app includes automatic updates.

To update through Homebrew, close the app and run:

```sh
brew update
brew upgrade --cask --greedy redharp/trevbot/trevbot-flash
```

Uninstall with `brew uninstall --cask redharp/trevbot/trevbot-flash`.
